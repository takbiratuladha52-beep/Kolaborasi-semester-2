Experience in Creating a Portfolio Website

Hello everyone, my name is Takbiratul Adha Syafitri from class X PPLG 3. On this occasion, I would like to share my experience in creating a portfolio website as one of the collaborative assignments given by my teachers.

Some time ago, I received an assignment to create a personal portfolio website. For this task, we were required to first design the layout using Figma, before moving on to the coding stage with HTML, CSS, and JavaScript. At first, I found it quite challenging because I had to think about the design appearance and adjust it to the code at the same time, so that the final result matched the plan I had made. The portfolio website I created consists of several sections, such as home, about me, skills, projects, contact, and footer. Through this assignment, I learned to develop my creativity and skills in building an attractive website.

The first step I took was to look for design inspirations from various websites on the internet. After finding several good references, I started designing in Figma, choosing color combinations, font styles, and layouts that are simple yet visually appealing. Once the design was finished, I began building the website structure with HTML, then styled it using CSS to make it look neat and modern. In addition, I also used JavaScript to add some simple effects, so that the website feels more dynamic and interactive when people use it.

During the development process, I encountered several difficulties. One of the biggest challenges was making sure the website layout stayed neat and well-organized across different screen sizes, both on laptops and mobile phones. I also ran into problems where images would not load, or the position of some sections shifted unexpectedly due to coding errors. Besides that, there were parts of the code that did not work as I intended, so I had to try many times before finding the right solution. Even though I felt tired and confused at times, I kept trying to fix every mistake by looking up tutorials and learning from these experiences.

From this project, I gained a lot of new knowledge about the website development process, ranging from UI/UX design to the actual coding stage. I now have a much better understanding of how to use HTML, CSS, JavaScript, and Figma to build a portfolio website. Moreover, I also learned to be more patient, thorough, and persistent when facing errors in my code. Even though the process was quite difficult, I feel proud and happy that I finally managed to complete a portfolio website entirely on my own.
